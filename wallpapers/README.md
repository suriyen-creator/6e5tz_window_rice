# Wallpaper Engine inventory

Workshop content is intentionally not copied into this repository.

Add entries here manually for wallpapers you want to restore:

```text
Name: <wallpaper name>
Workshop ID: <numeric id>
Workshop URL: https://steamcommunity.com/sharedfiles/filedetails/?id=<numeric id>
Notes: <local settings or installation notes>
```

The source machine had Wallpaper Engine installed under Steam, but no Workshop item was added to this inventory during the read-only inspection. Do not commit Workshop files unless you own and may redistribute them.
