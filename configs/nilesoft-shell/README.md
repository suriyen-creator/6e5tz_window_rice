# 🖱️ Nilesoft Shell (Catppuccin Mocha Context Menu)

Nilesoft Shell replaces the standard cluttered Windows 10/11 right-click context menu with a sleek, translucent Acrylic menu styled in the Catppuccin Mocha palette.

## Installation & Setup

1. **Download Nilesoft Shell**:
   - Download the installer from the official website: [nilesoft.org](https://nilesoft.org)
   - Or install via winget / scoop if available.
2. **Apply Config**:
   - Copy `shell.nss` from this folder to `C:\Program Files\Nilesoft Shell\shell.nss` (Run as Administrator)
   - Restart `explorer.exe` or press `Ctrl + Right-Click` on desktop to open Nilesoft Shell settings and reload.
