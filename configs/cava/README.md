# CAVA

- **`config`**: General CAVA configuration file (`~/.config/cava/config`).
- **`yasb_cava_config_1`**: Runtime audio visualizer configuration generated and utilized by YASB's cava widget (`%LOCALAPPDATA%\YASB\yasb_cava_config_1`). Features Catppuccin-styled gradients and responsive framerate/smoothing settings.
- **`themes/`**: CAVA color themes (`solarized_dark`, `tricolor`).
